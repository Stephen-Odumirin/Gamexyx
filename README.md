
# Gamexyz – v3 Parallax Theme

Major UI overhaul inspired by the Figma mock‑up.

## New Features
* **Sidebar navigation** with Lucide icons
* Parallax **topographic background** layers + giant text watermarks
* Hero section with CTA
* Featured carousel, Trending grid, Promo blocks, Video, Categories grid, Tournament teaser
* Fully themed Tournaments pages
* Footer
* Larger gutters, purple primary + amber accent

## Run

```bash
npm install
npm start
```

Opens on http://localhost:3000
