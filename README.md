# Gamexyx 🎮

**Gamexyx** is a sleek, dark-mode gaming portal where players connect their wallet, explore Unity WebGL games, and (coming soon) earn crypto rewards based on playtime and skill.  
This repository contains the **React-based front-end MVP** built with modern tooling like Tailwind, Framer Motion, and React Router v6.

> 🚀 **Live Preview:** https://gamexyx.vercel.app  
> 🛠️ **Status:** UI Complete · Wallet & Smart Contracts Coming Soon

---

## 🧩 Features

| UI Component         | Description |
|----------------------|-------------|
| 🎯 Hero Banner        | Catchy tagline + CTA to “Connect Wallet & Start Playing” |
| 🧭 Sidebar Navigation | Collapsible menu with icons (Games, Tournaments, Profile, etc.) |
| 🕹️ Game Carousels     | Horizontal sliders for “Featured” and “Trending” games |
| 🎮 Game Categories    | 10 tags like Arcade, Racing, Puzzle, FPS |
| 📽️ Game Detail Page   | Shows image, rating, YouTube trailer, description, and Start button |
| 📅 Tournament Preview | Weekly reward bracket with teaser section |
| 🌑 Dark Mode Design   | Purple-accented theme with modern gamer look |
| 📱 Responsive Layout  | Fully optimized for mobile-first but works great on desktop |
